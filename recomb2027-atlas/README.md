# GeoCert implementation and data

Start with the [repository README](../README.md) for installation, the count witness and experiment replays.

- `atlas/` and `geocert_expression/`: exact geometry and count solvers.
- `analysis/` and `tests/`: analysis entry points and algorithm checks.
- `artifact_parts/`: versioned base inputs, results and source archive.
- `extensions/`: union, donor, scaling and composition studies.
- `manuscript/`: current paper, supplement, LaTeX and figure inputs.
- `docs/`: data attribution, source provenance and study protocols.
- `release/`: result restoration, interval identities and PDF checksums.

[Archive instructions](ARCHIVE.md) explain how to restore the prepared data.
The optional acquisition scripts describe a separate planned study; they contribute no results to the paper.
